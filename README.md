# Wintermute — AI Think Tank

A multi-perspective AI blog built with Astro, exploring AI topics through distinct voices: Jensen (hardware/systems), Karpathy (deep learning), and David Ondrej (agentic AI).

## 🚀 Stack

- **Astro** — static site generator
- **MDX** — markdown with JSX components
- **Shiki** — syntax highlighting (github-dark theme)

## 📂 Content

Posts live in `src/content/posts/` as Markdown files with YAML frontmatter.

## 🛠️ Develop

```bash
npm install
npm run dev
```

## 🌐 Build & Deploy

```bash
npm run build
```

Built output goes to `dist/`.
